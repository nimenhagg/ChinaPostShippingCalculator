# 中国邮政资费速算宝 (ChinaPostShippingCalculator)

一个轻量、离线、零权限的中国邮政资费计算 Android 应用。旨在替代繁琐的官方小程序，提供清晰直观的邮件与包裹邮资测算体验。

## 核心特性

- **信函与明信片速算**：自动区分本埠（0.80元）与外埠（1.20元），无需手动选择省市区县。
- **国际与港澳台支持**：内置全球国家和地区即时拼音搜索，自动匹配资费组别与水陆路/航空资费。
- **包裹三大业务对比**：
  - **普通包裹（普包）**：支持最高 50kg，按全国 6 档阶梯计费（例如河北至四川 15kg 准确测算为 50 元）。
  - **快递包裹（快包）**：支持 500g 特惠及 1kg 首续重计费。
  - **特快专递（EMS）**：起重 500g 统一 20 元，并依分省资费表精准核算续重。
- **智能体积重计算**：内置邮政 1-6 号标准箱尺寸预设，严格按官方规则计泡。
- **隐私与极简**：完全离线运行，无需联网、无任何后台权限、无广告。

## 技术栈

- Kotlin + Jetpack Compose
- Material Design 3
- Android SDK 35 (最低支持 Android 8.0 / API 26)
